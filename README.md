# Node.js + Express Backend with MongoDB Atlas

## Setup

1. Copy `.env.example` to `.env` and fill in the details
2. Run `npm install` in `/backend`
3. Run `npm run dev` or `npm start`

## Directory Structure

- `src/app.js`: Express app setup
- `src/server.js`: Entry point
- `src/config/`: Configurations (`env.js`, `db.js`)
- `src/routes/`: Express routes
- `src/controllers/`: Controller logic
- `src/services/`: Service/business logic
- `src/middlewares/`: Custom middlewares
- `src/models/`: Mongoose models
- `src/utils/`: Helpers/utilities
- `src/validators/`: Zod schema validation
